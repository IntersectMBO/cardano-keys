Cardano.Keys.Pretty

Description

Turning the error documents of this package into text

The render*Error functions return Doc ann so that callers keep prettyprinter's grouping and wrapping. The two functions here are the layout this package pins for callers that just want a string: the default layout options, so that a document with no group in it renders as the concatenation of its parts.
